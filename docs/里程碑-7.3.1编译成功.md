## 追加：M5 Note 板级 dts 适配成功（2026-11-26 16:40）

**CI run**: `45784609274` success（缓存命中，~2 min）
**产物**: `kernel-mt6755-m5note-7.3.1` 15.2 MB，`Image.gz-dtb` 8.6 MB

### 实测设备数据（只读 SSH）
| 项 | 值 |
|---|---|
| 内存 | 2855084 kB ≈ **2.8 GB**（dts reg 改 0xb0000000） |
| 屏幕 | fb0 modes=`U:1080x1920p-0`，stride=4352，32bpp，虚拟 1088x3840 |
| 充电 IC | **BQ25890 @ i2c1 (0x11008000) 0x6b**（外置） |
| USB | `usb3@11270000`，reg 0x11270000/11280000/11290000，IRQ SPI 72+73 → **MTU3 SSUSB**（不是 musb！之前 6.12 判断错了） |
| 电源键 | `mediatek,kpd-pwrkey-eint-gpio`（EINT GPIO） |

### dts 适配内容（`mainline/7.3.1/dts/mt6755-m5note.dts`，181 行）
- model/compatible → `Meizu M5 Note (MT6755)` / `meizu,m5note`
- 内存 2G → 2.8G
- stdout-path → uart0（串口控制台）
- **删除 framebuffer 节点**（不接屏幕）
- 保留 `lk-overlay-sink` 全套 label（防 lk ASSERT 进 boot 循环）
- 保留 reserved-memory（ramoops/atf/preloader/lk/consys 等）

### 验证
从产物 `Image.gz-dtb` 的 dtb 里读到：`meizu,m5note`、`mediatek,mt6755`、`Meizu M5 Note (MT6755)` ✅

### 屏幕决策（用户："能轻松加就加，不行就算"）
**不加**。理由：k50v1 的 simple-framebuffer 依赖 lk 把 fb 放在固定的 `0x7f190000` 且 reserved；你设备的 reserved-memory 里**没有 framebuffer 节点**（fb 地址由 lk 通过 atag 动态传），无法确定物理地址。要加得先读 atag 或让 lk 保留 fb，风险高，放弃。
