### WiFi 失败的原因（最后一次 run 45673797491）

```
error: implicit declaration of 'timer_container_of'
error: 'tickfn' undeclared
```

这是 **connsys 面向 Linux 7.2/7.3，我们用了 6.12** 的 API 差异。
今天已回退了 4 类 API：
1. `sizeof(MacAddr.sa_data)` 柔性数组 → 14
2. cfg80211 回调 `wireless_dev*` → `net_device*`（9 个函数）
3. cookie `u64` ↔ `u64 *`（remain/mgmt_tx 用指针，cancel 用值）
4. `remain_on_channel` 删 `rx_addr` 参数

**但还有更多**（timer_container_of/tickfn），且这是无底洞。
